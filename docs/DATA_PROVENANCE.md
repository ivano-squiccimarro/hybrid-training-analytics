# Data provenance

No personal activity or user-training record is part of this repository.

| Material | Origin | Purpose |
|---|---|---|
| `examples/strength_synthetic.csv` | Invented values authored for this project | Small strength diary example |
| `examples/treadmill_synthetic.csv` | Invented settings | Treadmill log format example |
| `examples/*_template.csv` | Header-only templates | Local manual entry |
| FIT bytes in tests and demos | Generated by `synthetic.py` and `strength_synthetic.py` | CRC/parser checks and deterministic examples |
| `examples/demo-timeseries.svg` | Generated by the running demo, entirely synthetic | Lightweight README illustration |

The demo starts with invented samples; their timestamps are arbitrary fixtures,
not an athlete's activity. Synthetic numbers are not clinical/physiological
thresholds or evidence of predictive performance. FIT binaries are generated
locally, not committed. No private training context, original export, local
catalog, personal screenshot or historical operational log is included.

Reports record source SHA-256, schema, configuration, software versions and
output provenance. Preserve these alongside private outputs locally. A hash
identifies content; it does not establish sensor accuracy or clinical validity.
